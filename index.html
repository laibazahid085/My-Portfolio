About Me

Hello! I'm Laiba Zahid, a Full Stack Developer and DevOps Engineer based in Karachi, Pakistan. I specialize in building modern web applications and deploying them using DevOps practices and cloud technologies.

My development stack includes HTML, CSS, JavaScript, React, Node.js, Express, MongoDB, and SQL. Alongside development, I work with DevOps tools such as Linux, Docker, Kubernetes, Jenkins, GitHub Actions, and GitLab CI/CD to automate application builds, testing, and deployments.

I also have experience working with cloud platforms like AWS and Azure, including services such as EC2, S3, and cloud infrastructure management. I use tools like Terraform and Ansible for Infrastructure as Code and configuration automation.

My goal is to build scalable systems, efficient CI/CD pipelines, and modern web applications that solve real-world problems while following industry best practices.
